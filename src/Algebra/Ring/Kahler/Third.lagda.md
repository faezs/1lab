# The third exterior power and the Bianchi identity {defines="kahler-3-forms bianchi-identity"}

The pattern of the [[second exterior power|kahler-2-forms]]
continues: $\Omega^3_{A/R}$ is generated by symbols $\mathrm{d}a
\wedge \mathrm{d}b \wedge \mathrm{d}c$, trilinear and alternating,
subject to the Leibniz rule and vanishing on constants in each
slot. Its purpose here is a single theorem: the **Bianchi
identity** $\mathrm{d}F = 0$ — the field strength of any gauge
potential is a *closed* $2$-form. For electromagnetism this is half
of Maxwell's equations, and it is a purely algebraic consequence of
$\mathrm{d} \circ \mathrm{d} = 0$ pushed one degree up.

```agda
module _ (A : CRing ℓ) (φ : CR.Hom R A) where
  private module A = CRing-on (A .snd)

  data Ω³ : Type ℓ where
    d³⟨_,_,_⟩ : ⌞ A ⌟ → ⌞ A ⌟ → ⌞ A ⌟ → Ω³
    _·³_ : ⌞ A ⌟ → Ω³ → Ω³
    _+³_ : Ω³ → Ω³ → Ω³
    0³   : Ω³
    -³_  : Ω³ → Ω³

    +³-idl   : ∀ x → 0³ +³ x ≡ x
    +³-invr  : ∀ x → x +³ (-³ x) ≡ 0³
    +³-assoc : ∀ x y z → x +³ (y +³ z) ≡ (x +³ y) +³ z
    +³-comm  : ∀ x y → x +³ y ≡ y +³ x
    ·³-distl : ∀ a x y → a ·³ (x +³ y) ≡ (a ·³ x) +³ (a ·³ y)
    ·³-distr : ∀ a b x → (a A.+ b) ·³ x ≡ (a ·³ x) +³ (b ·³ x)
    ·³-assoc : ∀ a b x → a ·³ (b ·³ x) ≡ (a A.* b) ·³ x
    ·³-idl   : ∀ x → A.1r ·³ x ≡ x

    d³-+l : ∀ a a' b c
          → d³⟨ a A.+ a' , b , c ⟩ ≡ d³⟨ a , b , c ⟩ +³ d³⟨ a' , b , c ⟩
    d³-+m : ∀ a b b' c
          → d³⟨ a , b A.+ b' , c ⟩ ≡ d³⟨ a , b , c ⟩ +³ d³⟨ a , b' , c ⟩
    d³-+r : ∀ a b c c'
          → d³⟨ a , b , c A.+ c' ⟩ ≡ d³⟨ a , b , c ⟩ +³ d³⟨ a , b , c' ⟩
    d³-leibl : ∀ a a' b c
             → d³⟨ a A.* a' , b , c ⟩
             ≡ (a ·³ d³⟨ a' , b , c ⟩) +³ (a' ·³ d³⟨ a , b , c ⟩)
    d³-leibm : ∀ a b b' c
             → d³⟨ a , b A.* b' , c ⟩
             ≡ (b ·³ d³⟨ a , b' , c ⟩) +³ (b' ·³ d³⟨ a , b , c ⟩)
    d³-leibr : ∀ a b c c'
             → d³⟨ a , b , c A.* c' ⟩
             ≡ (c ·³ d³⟨ a , b , c' ⟩) +³ (c' ·³ d³⟨ a , b , c ⟩)
    d³-constl : ∀ r b c → d³⟨ φ .∫Hom.fst r , b , c ⟩ ≡ 0³
    d³-constm : ∀ a r c → d³⟨ a , φ .∫Hom.fst r , c ⟩ ≡ 0³
    d³-constr : ∀ a b r → d³⟨ a , b , φ .∫Hom.fst r ⟩ ≡ 0³
    d³-swapl : ∀ a b c → d³⟨ a , b , c ⟩ ≡ -³ d³⟨ b , a , c ⟩
    d³-swapr : ∀ a b c → d³⟨ a , b , c ⟩ ≡ -³ d³⟨ a , c , b ⟩
    d³-sql : ∀ a b → d³⟨ a , a , b ⟩ ≡ 0³
    d³-sqr : ∀ a b → d³⟨ a , b , b ⟩ ≡ 0³
    squash³ : is-set Ω³
```

The wedge of a function differential against a $2$-form is defined
by recursion, exactly as one degree down; each law of $\Omega^2$
lands on the corresponding law of $\Omega^3$, one slot over.

```agda
module _ {A : CRing ℓ} {φ : CR.Hom R A} where
  private module A = CRing-on (A .snd)

  wedge² : ⌞ A ⌟ → Ω² A φ → Ω³ A φ
  wedge² a (b d∧d c) = d³⟨ a , b , c ⟩
  wedge² a (b ·² x) = b ·³ wedge² a x
  wedge² a (x +² y) = wedge² a x +³ wedge² a y
  wedge² a 0² = 0³
  wedge² a (-² x) = -³ wedge² a x
```

Linearity in the *function* slot is a theorem, by induction; so is
the Leibniz rule, and vanishing at $1$.

```agda
  wedge²-+l
    : ∀ a b (x : Ω² A φ)
    → wedge² (a A.+ b) x ≡ wedge² a x +³ wedge² b x
  wedge²-+l a b = Ω²-elim-prop A φ
    (λ x → wedge² (a A.+ b) x ≡ wedge² a x +³ wedge² b x)
    (λ _ → squash³ _ _)
    (λ p q → d³-+l a b p q)
    (λ c x ih → ap (c ·³_) ih ∙ ·³-distl c (wedge² a x) (wedge² b x))
    (λ x ihx y ihy → ap₂ _+³_ ihx ihy
      ∙ +³-interchange (wedge² a x) (wedge² b x) (wedge² a y) (wedge² b y))
    (sym (+³-idl 0³))
    (λ x ih → ap -³_ ih ∙ neg-+³ (wedge² a x) (wedge² b x))

  wedge²-leib
    : ∀ a b (x : Ω² A φ)
    → wedge² (a A.* b) x ≡ (a ·³ wedge² b x) +³ (b ·³ wedge² a x)
  wedge²-leib a b = Ω²-elim-prop A φ
    (λ x → wedge² (a A.* b) x ≡ (a ·³ wedge² b x) +³ (b ·³ wedge² a x))
    (λ _ → squash³ _ _)
    (λ p q → d³-leibl a b p q)
    (λ c x ih →
        ap (c ·³_) ih
      ∙ ·³-distl c (a ·³ wedge² b x) (b ·³ wedge² a x)
      ∙ ap₂ _+³_
          ( ·³-assoc c a (wedge² b x)
          ∙ ap (_·³ wedge² b x) A.*-commutes
          ∙ sym (·³-assoc a c (wedge² b x)))
          ( ·³-assoc c b (wedge² a x)
          ∙ ap (_·³ wedge² a x) A.*-commutes
          ∙ sym (·³-assoc b c (wedge² a x))))
    (λ x ihx y ihy →
        ap₂ _+³_ ihx ihy
      ∙ +³-interchange (a ·³ wedge² b x) (b ·³ wedge² a x)
          (a ·³ wedge² b y) (b ·³ wedge² a y)
      ∙ sym (ap₂ _+³_
          (·³-distl a (wedge² b x) (wedge² b y))
          (·³-distl b (wedge² a x) (wedge² a y))))
    (sym (ap₂ _+³_ (·³-absorb a) (·³-absorb b) ∙ +³-idl 0³))
    (λ x ih → ap -³_ ih ∙ neg-+³ (a ·³ wedge² b x) (b ·³ wedge² a x)
      ∙ sym (ap₂ _+³_ (·³-neg a (wedge² b x)) (·³-neg b (wedge² a x))))

  wedge²-one : ∀ (x : Ω² A φ) → wedge² A.1r x ≡ 0³ {A = A} {φ}
  wedge²-one = Ω²-elim-prop A φ
    (λ x → wedge² A.1r x ≡ 0³)
    (λ _ → squash³ _ _)
    one-base
    (λ c x ih → ap (c ·³_) ih ∙ ·³-absorb c)
    (λ x ihx y ihy → ap₂ _+³_ ihx ihy ∙ +³-idl 0³)
    refl
    (λ x ih → ap -³_ ih ∙ neg-+³-zero)
    where
    one-image : φ .∫Hom.fst R.1r ≡ A.1r
    one-image = is-ring-hom.pres-id (φ .∫Hom.snd)

    one-base : ∀ b c → d³⟨ A.1r , b , c ⟩ ≡ 0³

      d³⟨ A.1r , b , c ⟩              ≡˘⟨ (λ i → d³⟨ one-image i , b , c ⟩) ⟩
      d³⟨ φ .∫Hom.fst R.1r , b , c ⟩  ≡⟨ d³-constl R.1r b c ⟩
      0³                              ∎
```

## The exterior derivative in degree two

The derivative $\mathrm{d} : \Omega^2 \to \Omega^3$ kills the
generators — they are already exact — and satisfies the graded
Leibniz rule on the module action. As in degree one, the recursion
is a paramorphism, computing the reconstruction alongside the
derivative.

```agda
  d²-aux : Ω² A φ → Ω² A φ × Ω³ A φ
  d²-aux (b d∧d c) = (b d∧d c) , 0³
  d²-aux (a ·² x) =
    let (copy , dx) = d²-aux x in
    a ·² copy , (wedge² a copy +³ (a ·³ dx))
  d²-aux (x +² y) =
    let (copy , dx) = d²-aux x
        (copy' , dy) = d²-aux y
    in copy +² copy' , dx +³ dy
  d²-aux 0² = 0² , 0³
  d²-aux (-² x) =
    let (copy , dx) = d²-aux x in
    -² copy , -³ dx
```

```agda
        ≡˘⟨ ap₂ _+³_ (+³-idr d³⟨ b , a , c ⟩) (+³-idr d³⟨ c , a , b ⟩) ⟩
      (d³⟨ b , a , c ⟩ +³ 0³) +³ (d³⟨ c , a , b ⟩ +³ 0³)
        ≡˘⟨ ap₂ (λ e f → (d³⟨ b , a , c ⟩ +³ e) +³ (d³⟨ c , a , b ⟩ +³ f))
              (·³-absorb b) (·³-absorb c) ⟩
      (d³⟨ b , a , c ⟩ +³ (b ·³ 0³)) +³ (d³⟨ c , a , b ⟩ +³ (c ·³ 0³))
        ∎
      where
      swap-chain : d³⟨ b , a , c ⟩ ≡ -³ d³⟨ c , a , b ⟩
      swap-chain =
        d³⟨ b , a , c ⟩         ≡⟨ d³-swapr b a c ⟩
        -³ d³⟨ b , c , a ⟩      ≡⟨ ap -³_ (d³-swapl b c a) ⟩
        -³ (-³ d³⟨ c , b , a ⟩) ≡⟨ ap (λ e → -³ (-³ e)) (d³-swapr c b a) ⟩
        -³ (-³ (-³ d³⟨ c , a , b ⟩)) ≡⟨ ap -³_ (-³-invol d³⟨ c , a , b ⟩) ⟩
        -³ d³⟨ c , a , b ⟩      ∎
  d²-aux (d∧d-constl r b i) = d∧d-constl r b i , 0³
  d²-aux (d∧d-constr a r i) = d∧d-constr a r i , 0³
  d²-aux (d∧d-antisym a b i) =
    d∧d-antisym a b i , sym (neg-+³-zero {A = A} {φ}) i
  d²-aux (d∧d-sq a i) = d∧d-sq a i , 0³
  d²-aux (squash² x y p q i j) =
    ×-is-hlevel 2 squash² squash³
      (d²-aux x) (d²-aux y) (λ i → d²-aux (p i)) (λ i → d²-aux (q i)) i j
```

```agda
  d² : Ω² A φ → Ω³ A φ
  d² x = d²-aux x .snd

  d²-d : ∀ a b → d² (a d∧d b) ≡ 0³
  d²-d a b = refl

  d²-+ : ∀ x y → d² (x +² y) ≡ d² x +³ d² y
  d²-+ x y = refl

  d²-aux-fst : (x : Ω² A φ) → d²-aux x .fst ≡ x
  d²-aux-fst = Ω²-elim-prop A φ
    (λ x → d²-aux x .fst ≡ x)
    (λ _ → squash² _ _)
    (λ a b → refl)
    (λ a x ih → ap (a ·²_) ih)
    (λ x ihx y ihy → ap₂ _+²_ ihx ihy)
    refl
    (λ x ih → ap -²_ ih)
```

## The Bianchi identity

Two exchange lemmas, both inductions over $\Omega^1$: wedging twice
anticommutes, and the derivative of a wedge is minus the wedge of
the derivative — the graded Leibniz rule for a degree-$1$ form
whose own derivative vanishes.

```agda
  wedge²-swap
    : ∀ a b (ω : Ω¹ A φ)
    → wedge² a (wedge b ω) ≡ -³ wedge² b (wedge a ω)
  wedge²-swap a b = Ω¹-elim-prop A φ
    (λ ω → wedge² a (wedge b ω) ≡ -³ wedge² b (wedge a ω))
    (λ _ → squash³ _ _)
    (λ c → d³-swapl a b c)
    (λ c ω ih → ap (c ·³_) ih ∙ ·³-neg c (wedge² b (wedge a ω)))
    (λ x ihx y ihy → ap₂ _+³_ ihx ihy
      ∙ sym (neg-+³ (wedge² b (wedge a x)) (wedge² b (wedge a y))))
    (sym neg-+³-zero)
    (λ x ih → ap -³_ ih)

  d²-wedge
    : ∀ a (ω : Ω¹ A φ)
    → d² (wedge a ω) ≡ -³ wedge² a (d¹ ω)
  d²-wedge a = Ω¹-elim-prop A φ
    (λ ω → d² (wedge a ω) ≡ -³ wedge² a (d¹ ω))
    (λ _ → squash³ _ _)
    (λ b → sym neg-+³-zero)
    ·-case
    (λ x ihx y ihy → ap₂ _+³_ ihx ihy
      ∙ sym (neg-+³ (wedge² a (d¹ x)) (wedge² a (d¹ y))))
    (sym neg-+³-zero)
    (λ x ih → ap -³_ ih)
    where
    ·-case
      : ∀ b ω
      → d² (wedge a ω) ≡ -³ wedge² a (d¹ ω)
      → d² (wedge a (b ·ω ω)) ≡ -³ wedge² a (d¹ (b ·ω ω))
    ·-case b ω ih =
      wedge² b (d²-aux (wedge a ω) .fst) +³ (b ·³ d² (wedge a ω))
        ≡⟨ ap₂ _+³_
             (ap (wedge² b) (d²-aux-fst (wedge a ω)))
             (ap (b ·³_) ih ∙ ·³-neg b (wedge² a (d¹ ω))) ⟩
      wedge² b (wedge a ω) +³ (-³ (b ·³ wedge² a (d¹ ω)))
        ≡⟨ ap (_+³ (-³ (b ·³ wedge² a (d¹ ω)))) (wedge²-swap b a ω) ⟩
      (-³ wedge² a (wedge b ω)) +³ (-³ (b ·³ wedge² a (d¹ ω)))
        ≡˘⟨ neg-+³ (wedge² a (wedge b ω)) (b ·³ wedge² a (d¹ ω)) ⟩
      -³ (wedge² a (wedge b ω) +³ (b ·³ wedge² a (d¹ ω)))
        ≡˘⟨ ap (λ e → -³ (wedge² a (wedge b e) +³ (b ·³ wedge² a (d¹ ω))))
              (d¹-aux-fst ω) ⟩
      -³ (wedge² a (wedge b (d¹-aux ω .fst)) +³ (b ·³ wedge² a (d¹ ω)))
        ∎
```

The Bianchi identity follows by one more induction: on generators
both sides vanish; on the module action the two Leibniz terms
cancel against each other by the exchange lemmas; and the group
structure passes through.

```agda
  bianchi : (ω : Ω¹ A φ) → d² (d¹ ω) ≡ 0³
  bianchi = Ω¹-elim-prop A φ
    (λ ω → d² (d¹ ω) ≡ 0³)
    (λ _ → squash³ _ _)
    (λ a → refl)
    ·-case
    (λ x ihx y ihy → ap₂ _+³_ ihx ihy ∙ +³-idl 0³)
    refl
    (λ x ih → ap -³_ ih ∙ neg-+³-zero)
    where
    ·-case
      : ∀ a ω → d² (d¹ ω) ≡ 0³
      → d² (d¹ (a ·ω ω)) ≡ 0³
    ·-case a ω ih =
      d² (wedge a (d¹-aux ω .fst)) +³ (wedge² a (d²-aux (d¹ ω) .fst) +³ (a ·³ d² (d¹ ω)))
        ≡⟨ ap₂ _+³_
             ( ap (λ e → d² (wedge a e)) (d¹-aux-fst ω)
             ∙ d²-wedge a ω)
             ( ap₂ _+³_
                 (ap (wedge² a) (d²-aux-fst (d¹ ω)))
                 (ap (a ·³_) ih ∙ ·³-absorb a)
             ∙ +³-idr (wedge² a (d¹ ω))) ⟩
      (-³ wedge² a (d¹ ω)) +³ wedge² a (d¹ ω)
        ≡⟨ +³-invl (wedge² a (d¹ ω)) ⟩
      0³
        ∎
```

Instantiated over the [[Deligne presentation|deligne-complex]] of
the gauge groupoid, this says exactly that the [[field
strength|gauge-groupoid]] $F = \mathrm{d}A$ of any gauge potential
is closed: $\mathrm{d}F = 0$, half of Maxwell's equations, for
every probe and every potential at once.
