# Kähler differentials {defines="kahler-differentials universal-derivation"}

For a commutative $R$-algebra $A$, the module of **Kähler
differentials** $\Omega^1_{A/R}$ is the universal home for
derivatives of elements of $A$: it is generated by symbols
$\mathrm{d}a$, subject to additivity, the Leibniz rule, and the
vanishing of $\mathrm{d}$ on the constants from $R$. It is the
algebraic incarnation of the cotangent space, and — dualising — the
reason the tangent bundle of the previous sections has the expected
fibres.

As with the [[polynomial ring|polynomial-ring]], we present it
directly as a higher inductive type: point constructors for the
generators and the module operations, path constructors for exactly
the laws, and set truncation.

```agda
module _ (A : CRing ℓ) (φ : CR.Hom R A) where
  private module A = CRing-on (A .snd)

  data Ω¹ : Type ℓ where
    dₖ   : ⌞ A ⌟ → Ω¹
    _·ω_ : ⌞ A ⌟ → Ω¹ → Ω¹
    _+ω_ : Ω¹ → Ω¹ → Ω¹
    0ω   : Ω¹
    -ω_  : Ω¹ → Ω¹

    +ω-idl    : ∀ x → 0ω +ω x ≡ x
    +ω-invr   : ∀ x → x +ω (-ω x) ≡ 0ω
    +ω-assoc  : ∀ x y z → x +ω (y +ω z) ≡ (x +ω y) +ω z
    +ω-comm   : ∀ x y → x +ω y ≡ y +ω x
    ·ω-distl  : ∀ a x y → a ·ω (x +ω y) ≡ (a ·ω x) +ω (a ·ω y)
    ·ω-distr  : ∀ a b x → (a A.+ b) ·ω x ≡ (a ·ω x) +ω (b ·ω x)
    ·ω-assoc  : ∀ a b x → a ·ω (b ·ω x) ≡ (a A.* b) ·ω x
    ·ω-idl    : ∀ x → A.1r ·ω x ≡ x
    d-+       : ∀ a b → dₖ (a A.+ b) ≡ dₖ a +ω dₖ b
    d-leibniz : ∀ a b → dₖ (a A.* b) ≡ (a ·ω dₖ b) +ω (b ·ω dₖ a)
    d-const   : ∀ r → dₖ (φ .∫Hom.fst r) ≡ 0ω
    squashω   : is-set Ω¹
```

<details>
<summary>The eliminator into families of propositions is derived by
reflection, as usual.</summary>

  Ω¹-elim-prop
    : ∀ {ℓ'} (B : Ω¹ → Type ℓ')
    → (∀ x → is-prop (B x))
    → (∀ a → B (dₖ a))
    → (∀ a x → B x → B (a ·ω x))
    → (∀ x → B x → ∀ y → B y → B (x +ω y))
    → B 0ω
    → (∀ x → B x → B (-ω x))
    → ∀ x → B x

## Functoriality

An algebra map $f : A \to B$ under $R$ pushes differentials forward,
$\mathrm{d}a \mapsto \mathrm{d}(f\,a)$; the Leibniz rule transports
along preservation of multiplication, and vanishing on constants
transports along the commuting triangle over $R$.

```agda
module _ {A B : CRing ℓ} {φA : CR.Hom R A} {φB : CR.Hom R B}
         (f : CR.Hom A B) (comm : f CR.∘ φA ≡ φB)
  where

  private
    module A = CRing-on (A .snd)
    module B = CRing-on (B .snd)
    module f = is-ring-hom (f .∫Hom.snd)

    f₀ : ⌞ A ⌟ → ⌞ B ⌟
    f₀ = f .∫Hom.fst

  Ω¹-map : Ω¹ A φA → Ω¹ B φB
  Ω¹-map (dₖ a) = dₖ (f₀ a)
  Ω¹-map (a ·ω x) = f₀ a ·ω Ω¹-map x
  Ω¹-map (x +ω y) = Ω¹-map x +ω Ω¹-map y
  Ω¹-map 0ω = 0ω
  Ω¹-map (-ω x) = -ω Ω¹-map x

  Ω¹-map (+ω-idl x i) = +ω-idl (Ω¹-map x) i
  Ω¹-map (+ω-invr x i) = +ω-invr (Ω¹-map x) i
  Ω¹-map (+ω-assoc x y z i) =
    +ω-assoc (Ω¹-map x) (Ω¹-map y) (Ω¹-map z) i
  Ω¹-map (+ω-comm x y i) = +ω-comm (Ω¹-map x) (Ω¹-map y) i
  Ω¹-map (·ω-distl a x y i) =
    ·ω-distl (f₀ a) (Ω¹-map x) (Ω¹-map y) i
  Ω¹-map (·ω-distr a b x i) =
    ( ap (_·ω Ω¹-map x) (f.pres-+ a b)
    ∙ ·ω-distr (f₀ a) (f₀ b) (Ω¹-map x)) i
  Ω¹-map (·ω-assoc a b x i) =
    ( ·ω-assoc (f₀ a) (f₀ b) (Ω¹-map x)
    ∙ ap (_·ω Ω¹-map x) (sym (f.pres-* a b))) i
  Ω¹-map (·ω-idl x i) =
    (ap (_·ω Ω¹-map x) f.pres-id ∙ ·ω-idl (Ω¹-map x)) i
  Ω¹-map (d-+ a b i) =
    (ap dₖ (f.pres-+ a b) ∙ d-+ (f₀ a) (f₀ b)) i
  Ω¹-map (d-leibniz a b i) =
    (ap dₖ (f.pres-* a b) ∙ d-leibniz (f₀ a) (f₀ b)) i
  Ω¹-map (d-const r i) =
    ( ap dₖ (ap (λ e → e .∫Hom.fst r) comm)
    ∙ d-const r) i
  Ω¹-map (squashω x y p q i j) = squashω
    (Ω¹-map x) (Ω¹-map y) (λ i → Ω¹-map (p i)) (λ i → Ω¹-map (q i)) i j
```
