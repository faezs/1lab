# Extending presheaves from the reduced category {defines="presheaf-extension"}

Proposition 1.1(iii) of Belfiore–Bennequin: every presheaf on the
reduced category $C_{\mathbf X}$ — ordinary and tang vertices only —
extends to a sheaf on the whole forked site, by *defining* the value
at each star to be the product of the values at the fork's inputs.
The extension is a functorial section of restriction; this module
constructs it on objects and proves the sheaf condition. Note that a
hom-set of the reduced category *is* a hom-set of the site, so a
presheaf on $C_{\mathbf X}$ can be applied to any path between plain
vertices directly.

```agda
  ORIG : Fin (N .size) → ⌞ Reduced N ⌟
  ORIG c = orig c , tt

  TANG : (c : Fin (N .size)) → is-fork N c → ⌞ Reduced N ⌟
  TANG c f = tang c f , tt

  Ext₀ : F-vtx N → Type ℓ
  Ext₀ (orig c)   = F ʻ ORIG c
  Ext₀ (star c f) = (i : Fin (length (N .inputs c))) → F ʻ ORIG (N .inputs c ! i)
  Ext₀ (tang c f) = F ʻ TANG c f

  private
    Ext₀-is-set : ∀ v → is-set (Ext₀ v)
    Ext₀-is-set (orig c)   = F.₀ (ORIG c) .is-tr
    Ext₀-is-set (star c f) = Π-is-hlevel 2 λ i → F.₀ _ .is-tr
    Ext₀-is-set (tang c f) = F.₀ (TANG c f) .is-tr

  ρₑ : ∀ {v u} (e : F-edge N v u) → Ext₀ u → Ext₀ v
  ρₑ {orig c} {orig b} (single q) x =
    F.₁ {ORIG b} {ORIG c} (cons (single q) nil) x
  ρₑ (tine i q) s = subst (λ m → F ʻ ORIG m) q (s i)
  ρₑ {star c f} {tang c' f'} (socket {f = fs} {f' = fs'}) x = λ i →
    F.₁ {TANG c' f'} {ORIG (N .inputs c ! i)}
      (cons (tine i refl) (cons (socket {f = fs} {f' = fs'}) nil)) x
  ρₑ {orig c} {tang c' f'} handle x =
    F.₁ {TANG c' f'} {ORIG c} (cons handle nil) x

  ρ : ∀ {v u} → Path-in Γ v u → Ext₀ u → Ext₀ v
  ρ nil        x = x
  ρ (cons e p) x = ρₑ e (ρ p x)

  private
    ρ-++
      : ∀ {v m u} (p : Path-in Γ v m) (q : Path-in Γ m u) (x : Ext₀ u)
      → ρ (p ++ q) x ≡ ρ p (ρ q x)
    ρ-++ nil        q x = refl
    ρ-++ (cons e p) q x = ap (ρₑ e) (ρ-++ p q x)

  Ext : Functor ((fork-site N) ^op) (Sets ℓ)
  Ext .Functor.F₀ v = el (Ext₀ v) (Ext₀-is-set v)
  Ext .Functor.F₁ = ρ
  Ext .Functor.F-id = refl
  Ext .Functor.F-∘ f g = funext (ρ-++ f g)
```

## The sheaf condition

The proof is word-for-word the free-generation argument of the
[[explicit sheafification|explicit-sheafification]]: at a star, the
glue of a patch is the tuple of its parts at the canonical tines,
and every arrow of the tine sieve restricts correctly, by induction
with the patch condition absorbing each prefix edge; at ordinary and
tang vertices the covering sieve is generated by the identity.

```agda
  private
    tine-mem
      : ∀ {c} {f : is-fork N c} (i : Fin (length (N .inputs c)))
      → cons (tine {f = f} i refl) nil ∈ ⟦ tine-cover N c f ⟧
    tine-mem i = inc (i , nil , refl)

  sheaf-at-star
    : ∀ {c} {f : is-fork N c}
    → is-sheaf₁ Ext ⟦ tine-cover N c f ⟧
  sheaf-at-star {c} {f} ps = contr sec λ s → Section-path {A = Ext} $
    funext λ i →
      sym (s .glues (cons (tine i refl) nil) (tine-mem i))
      ∙ transport-refl _
    where
      whole' : Ext₀ (star c f)
      whole' i = ps .part (cons (tine {f = f} i refl) nil) (tine-mem i)

      glue-lemma
        : ∀ {w} (g : Path-in Γ w (star c f))
        → (hg : g ∈ ⟦ tine-cover N c f ⟧)
        → ρ g whole' ≡ ps .part g hg
      glue-lemma nil hg = absurd
        (Equiv.to (covers-star-is-nonempty N nil) hg)
      glue-lemma (cons (tine i q) nil) hg =
        J (λ b q →
            ∀ (hg : cons (tine {b = b} {f = f} i q) nil ∈ ⟦ tine-cover N c f ⟧)
            → ρ (cons (tine {b = b} {f = f} i q) nil) whole'
            ≡ ps .part (cons (tine {b = b} {f = f} i q) nil) hg)
          (λ hg → transport-refl _ ∙ app ps refl)
          q hg
      glue-lemma (cons e (cons e' p)) hg =
        ap (ρₑ e) (glue-lemma (cons e' p) (into-star-covers N (cons e' p) tt))
        ∙ ps .patch (cons e' p) (into-star-covers N (cons e' p) tt) (cons e nil) hg

      sec : Section Ext ps
      sec .whole = whole'
      sec .glues = glue-lemma

  sheaf-at-id
    : ∀ (U : F-vtx N)
    → (∀ {w} (g : Path-in Γ w U) → g ∈ ⟦ canonical N U ⟧)
    → is-sheaf₁ Ext ⟦ canonical N U ⟧
  sheaf-at-id U total ps = contr sec λ s → Section-path {A = Ext} $
    sym (s .glues nil (total nil))
    where
      sec : Section Ext ps
      sec .whole = ps .part nil (total nil)
      sec .glues g hg =
          ps .patch nil (total nil) g (total (g ++ nil))
        ∙ app ps (++-idr g)

  Ext-is-sheaf : is-sheaf (fork-coverage N) Ext
  Ext-is-sheaf = from-is-sheaf₁ λ {U} c → go U where
    go : ∀ U → is-sheaf₁ Ext ⟦ canonical N U ⟧
    go (orig c)   = sheaf-at-id (orig c) λ g → inc (tt , g , ++-idr g)
    go (star c f) = sheaf-at-star
    go (tang c f) = sheaf-at-id (tang c f) λ g → inc (tt , g , ++-idr g)
```

Restriction of the extension back to the reduced category recovers
the original presheaf on objects definitionally; the natural
isomorphism, and the converse composite on sheaves via the
[[star-value]] equivalence, are the successor milestone assembling
Proposition 1.1's corollary $\mathrm{Sh}(C,J) \simeq
\mathrm{PSh}(C_{\mathbf X})$.
