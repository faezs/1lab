# Explicit sheafification on a forked site {defines="explicit-sheafification"}

Belfiore–Bennequin observe (§1.3) that sheafification for the [[tine
coverage]] is *explicit*: nothing changes except at the stars, where
the value is replaced by the product of the values at the fork's
inputs, with the tines acting by projections. This module carries
that out, and proves the resulting presheaf **is** a sheaf, directly
from the universal property of the product.

The structural reason this works — which the paper does not isolate —
is that the site is a *free* category: a path into a star that isn't
the identity ends in a uniquely determined tine, with a uniquely
determined prefix. So the sieve generated by the tines is *freely*
generated: a patch over it has no cross-tine compatibility conditions
to satisfy, and its data reduces to one element per tine. Gluing is
then just tupling.

## The sheafified presheaf

On objects: identity at ordinary and tang vertices, the product of
the input values at a star.

```agda
  X⋆₀ : F-vtx N → Type ℓ
  X⋆₀ (orig c)   = X ʻ orig c
  X⋆₀ (star c f) = (i : Fin (length (N .inputs c))) → X ʻ orig (N .inputs c ! i)
  X⋆₀ (tang c f) = X ʻ tang c f

  private
    X⋆₀-is-set : ∀ v → is-set (X⋆₀ v)
    X⋆₀-is-set (orig c)   = X.₀ (orig c) .is-tr
    X⋆₀-is-set (star c f) = Π-is-hlevel 2 λ i → X.₀ _ .is-tr
    X⋆₀-is-set (tang c f) = X.₀ (tang c f) .is-tr
```

On edges: single-input transmissions and handles restrict exactly as
they did in $X$; a tine projects the corresponding factor; and the
socket $A^\star_c \to A_c$ restricts by the tuple of $X$'s
restrictions along the composites $\mathrm{orig}\,b_i \to A^\star_c
\to A_c$. Restriction along a general path is the fold of the edge
actions, which is functorial on the nose.

```agda
  ρₑ : ∀ {v u} (e : F-edge N v u) → X⋆₀ u → X⋆₀ v
  ρₑ (single q)   x = X.₁ (cons (single q) nil) x
  ρₑ (tine i q)   s = subst (λ m → X ʻ orig m) q (s i)
  ρₑ (socket {f = f} {f' = f'}) x = λ i →
    X.₁ (cons (tine i refl) (cons (socket {f = f} {f' = f'}) nil)) x
  ρₑ handle       x = X.₁ (cons handle nil) x

  ρ : ∀ {v u} → Path-in Γ v u → X⋆₀ u → X⋆₀ v
  ρ nil        x = x
  ρ (cons e p) x = ρₑ e (ρ p x)

  private
    ρ-++
      : ∀ {v m u} (p : Path-in Γ v m) (q : Path-in Γ m u) (x : X⋆₀ u)
      → ρ (p ++ q) x ≡ ρ p (ρ q x)
    ρ-++ nil        q x = refl
    ρ-++ (cons e p) q x = ap (ρₑ e) (ρ-++ p q x)

  X⋆ : Functor ((fork-site N) ^op) (Sets ℓ)
  X⋆ .Functor.F₀ v = el (X⋆₀ v) (X⋆₀-is-set v)
  X⋆ .Functor.F₁ = ρ
  X⋆ .Functor.F-id = refl
  X⋆ .Functor.F-∘ f g = funext (ρ-++ f g)
```

## The sheaf condition

At a star, the covering sieve is generated by the tines; the glue of
a patch is the tuple of its parts at the canonical tines, and the
inductive lemma below — the free generation of the sieve — shows
this tuple restricts correctly along *every* arrow of the sieve: a
one-edge arrow is a tine, whose restriction is a projection of the
tuple, and a longer arrow is a precomposition of a shorter one,
handled by the patch condition.

```agda
  private
    tine-mem
      : ∀ {c} {f : is-fork N c} (i : Fin (length (N .inputs c)))
      → cons (tine {f = f} i refl) nil ∈ ⟦ tine-cover N c f ⟧
    tine-mem i = inc (i , nil , refl)

  sheaf-at-star
    : ∀ {c} {f : is-fork N c}
    → is-sheaf₁ X⋆ ⟦ tine-cover N c f ⟧
  sheaf-at-star {c} {f} ps = contr sec λ s → Section-path {A = X⋆} $
    funext λ i →
      sym (s .glues (cons (tine i refl) nil) (tine-mem i))
      ∙ transport-refl _
    where
      whole' : X⋆₀ (star c f)
      whole' i = ps .part (cons (tine {f = f} i refl) nil) (tine-mem i)

      glue-lemma
        : ∀ {w} (g : Path-in Γ w (star c f))
        → (hg : g ∈ ⟦ tine-cover N c f ⟧)
        → ρ g whole' ≡ ps .part g hg
      glue-lemma nil hg = absurd
        (Equiv.to (covers-star-is-nonempty N nil) hg)
      glue-lemma (cons (tine i q) nil) hg =
        J (λ b q →
            ∀ (hg : cons (tine {b = b} {f = f} i q) nil ∈ ⟦ tine-cover N c f ⟧)
            → ρ (cons (tine {b = b} {f = f} i q) nil) whole'
            ≡ ps .part (cons (tine {b = b} {f = f} i q) nil) hg)
          (λ hg → transport-refl _ ∙ app ps refl)
          q hg
      glue-lemma (cons e (cons e' p)) hg =
        ap (ρₑ e) (glue-lemma (cons e' p) (into-star-covers N (cons e' p) tt))
        ∙ ps .patch (cons e' p) (into-star-covers N (cons e' p) tt) (cons e nil) hg

      sec : Section X⋆ ps
      sec .whole = whole'
      sec .glues = glue-lemma
```

At ordinary and tang vertices, the canonical covering sieve is
generated by the identity, so the sheaf condition is immediate: the
part at the identity is the glue, and it is unique.

```agda
  sheaf-at-id
    : ∀ (U : F-vtx N)
    → (∀ {w} (g : Path-in Γ w U) → g ∈ ⟦ canonical N U ⟧)
    → is-sheaf₁ X⋆ ⟦ canonical N U ⟧
  sheaf-at-id U total ps = contr sec λ s → Section-path {A = X⋆} $
    sym (s .glues nil (total nil))
    where
      sec : Section X⋆ ps
      sec .whole = ps .part nil (total nil)
      sec .glues g hg =
          ps .patch nil (total nil) g (total (g ++ nil))
        ∙ app ps (++-idr g)
```

Assembling: at stars the canonical cover *is* the tine cover, and at
the other vertices every arrow lies in the identity-generated sieve.

```agda
  X⋆-is-sheaf : is-sheaf (fork-coverage N) X⋆
  X⋆-is-sheaf = from-is-sheaf₁ λ {U} c → go U where
    go : ∀ U → is-sheaf₁ X⋆ ⟦ canonical N U ⟧
    go (orig c)   = sheaf-at-id (orig c) λ g → inc (tt , g , ++-idr g)
    go (star c f) = sheaf-at-star
    go (tang c f) = sheaf-at-id (tang c f) λ g → inc (tt , g , ++-idr g)
```
