# The tine coverage {defines="tine-coverage"}

The Grothendieck topology $J$ on the site of a DNN (§1.3 of
Belfiore–Bennequin) has exactly one non-trivial feature: each star
vertex $A^\star_c$ is covered by its *tines*, the family of arrows
arriving from the inputs of the fork $c$. The sheaf condition for
this coverage is what forces the value at $A^\star_c$ to be the
product of the values at the inputs — the joint state a fork
consumes.

We define the coverage *faithfully*: the covering sieve at a star is
the sieve **generated by the tine family**, using the library's
machinery for coverage bases (`from-families`{.Agda}); every other
object is covered by the sieve generated by its identity, i.e.
maximally. This is the first nontrivial `Coverage`{.Agda}
instantiated on this branch. The paper asserts, implicitly and
without proof, that $J$ is well-defined; the *stability* proof below
rests on the arrow inventory of [`Neural.Graph.Fork`] — the only
edges into a star are tines — through one lemma: every nonempty path
into a star belongs to the sieve its tines generate.

[`Neural.Graph.Fork`]: Neural.Graph.Fork.html

The canonical covering family of each vertex: at a star, the tines,
indexed by the *positions* of the fork's input list — this is
literally the paper's family — and at any other vertex, the identity.

```agda
  tine-cover
    : ∀ (c : Fin (N .size)) (f : is-fork N c)
    → Cover (fork-site N) (star c f) lzero
  tine-cover c f .index    = Fin (length (N .inputs c))
  tine-cover c f .domain i = orig (N .inputs c ! i)
  tine-cover c f .map i    = cons (tine i refl) nil

  canonical : (U : F-vtx N) → Cover (fork-site N) U lzero
  canonical (orig c)   = record { map = λ (_ : ⊤) → nil }
  canonical (star c f) = tine-cover c f
  canonical (tang c f) = record { map = λ (_ : ⊤) → nil }
```

The key lemma. Membership in the sieve generated by a cover is the
mere existence of a factorization through one of its maps; here,
every *nonempty* path into a star lies in the sieve generated by the
tines. The induction is pleasantly definitional: a path consisting of
a single edge into the star must *be* a tine (there is nothing else),
and we recurse on the position witness so that the canonical
position-indexed tine appears; a longer path is a precomposition of a
shorter one, and sieves are closed under precomposition.

```agda
  into-star-covers
    : ∀ {v c} {f : is-fork N c}
    → (p : Path-in (fork-graph N) v (star c f))
    → ∣ nonempty N p ∣
    → p ∈ ⟦ tine-cover c f ⟧
  into-star-covers (cons (tine i q) nil) _ =
    J (λ b q → cons (tine i q) nil ∈ ⟦ tine-cover _ _ ⟧)
      (inc (i , nil , refl)) q
  into-star-covers (cons e (cons e' p)) _ =
    ⟦ tine-cover _ _ ⟧ .closed (into-star-covers (cons e' p) tt) (cons e nil)
```

Conversely, everything in the generated sieve is nonempty, so the
generated sieve is *exactly* the sieve of nonempty arrows — the
shortcut description that makes computations downstream pleasant.

```agda
  covers-star-is-nonempty
    : ∀ {v c} {f : is-fork N c}
    → (p : Path-in (fork-graph N) v (star c f))
    → p ∈ ⟦ tine-cover c f ⟧ ≃ ∣ nonempty N p ∣
  covers-star-is-nonempty {v} {c} {f} p =
    prop-ext (hlevel 1) (nonempty N p .is-tr)
      (rec! λ i h eq → subst (λ q → ∣ nonempty N q ∣) eq
        (++-nonempty-r N h tt))
      (into-star-covers p)
```

## The coverage

Stability, in the basis formulation: for every map $h : V \to U$ and
the canonical family of $U$, the canonical family of $V$ must land,
after composition with $h$, in the sieve generated by $U$'s family.
When $U$ is not a star its family generates a maximal-like sieve and
the factorization is trivial; when $U$ is a star, each composite is a
nonempty path into the star, and the key lemma applies. In every
case the covering of $V$ we exhibit is its canonical one.

```agda
  fork-coverings : Coverings (fork-site N) lzero lzero
  fork-coverings .covers _ = ⊤
  fork-coverings .family {U} _ = canonical U

  fork-coverings .stable {U = orig c} S h = inc (tt , λ i →
    inc (tt , h Path-category.∘ canonical _ .map i , ++-idr _))
    where module Path-category = Precategory (fork-site N)
  fork-coverings .stable {U = tang c f} S h = inc (tt , λ i →
    inc (tt , h Path-category.∘ canonical _ .map i , ++-idr _))
    where module Path-category = Precategory (fork-site N)
  fork-coverings .stable {U = star c f} S nil = inc (tt , λ i →
    into-star-covers (canonical (star c f) .map i ++ nil)
      (++-nonempty-l N (canonical (star c f) .map i) {q = nil} tt))
  fork-coverings .stable {U = star c f} {V = V} S (cons e p) = inc (tt , λ i →
    into-star-covers (canonical V .map i ++ cons e p)
      (++-nonempty-r N (canonical V .map i) {q = cons e p} tt))

  fork-coverage : Coverage (fork-site N) lzero
  fork-coverage = from-families fork-coverings
```
